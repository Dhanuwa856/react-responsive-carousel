# React Image Carousel Component

This is a fully customizable and responsive Image Carousel component built with React, Tailwind CSS, and React Icons. The carousel supports multiple images, navigation arrows, automatic sliding, slide indicators, customizable arrow button colors, and drag/swipe support on desktop and mobile devices.

## Features

- **Multiple Images:**  
  Display more than one image at a time. Each image can be provided as a string (URL) or as an object with `url` and optional `alt` text.
- **Navigation Arrows:**  
  Use left and right arrow buttons to navigate between images. Customize the appearance of these buttons with your own Tailwind CSS classes.

- **Automatic Sliding:**  
  Enable automatic sliding with a configurable interval.

- **Indicators:**  
  Dot indicators show the current slide and allow users to jump directly to any image.

- **Drag/Swipe Support:**  
  Supports dragging or swiping to navigate between images on both desktop and mobile devices.

- **Customizable Sizing:**  
  Adjust the carousel's width and height via Tailwind CSS classes.

## Installation

1. **Prerequisites:**  
   Ensure you have a React project with [Tailwind CSS](https://tailwindcss.com/docs/installation) installed and configured.

2. **Install React Icons:**  
   If not already installed, add `react-icons` to your project:
   ```bash
   npm install react-icons
   ```
